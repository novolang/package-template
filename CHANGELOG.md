# Changelog

Every published version, newest first. This file is on the publish
allow-list, so it travels with the package: it is the only thing a
consumer deciding whether to upgrade can read.

Write one entry per released version, under a heading that is the
version and the date. Say what changed for a *caller* — a signature, a
behaviour, a floor — not what changed in the diff. A breaking change
gets a **Migration** line saying what to write instead.
